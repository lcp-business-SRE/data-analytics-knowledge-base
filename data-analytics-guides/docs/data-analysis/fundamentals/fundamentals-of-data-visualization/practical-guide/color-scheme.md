# 1-7. 戦略的に色を使おう

## 色は可視化の強い味方

グラフを作成するときに重要なのが、色の使い方です。  
色は組み合わせることによってあらゆる効果を発揮し、グラフをよりわかりやすくすることができます。  
また、カラーユニバーサルデザイン（CUD）を意識することで、色覚の違いにかかわらず、情報を正しく伝えられます。  

デフォルトの色をそのまま使うのではなく、**戦略的に色を使う**ことで、グラフの情報伝達力を高める方法を学びましょう。

## 3つの配色の使い分け

配色とは色の組み合わせのことですが、組み合わせ方によって異なる効果を生み出すことができます。  
ここではグラフに効果的な3パターンを紹介します。  
伝えたい内容や目的に応じて、適切な配色を選べるようになりましょう。

### 1. カテゴリカルカラー（区別する）

カテゴリカルカラーは、その名の通りカテゴリーごとに区別するための配色です。

### 2．シーケンシャルカラー（量の大小を表す）

シーケンシャルカラーは、同じ色のグラデーションによって量の大小を表す配色です。  
淡い色は小さい値、濃い色は大きい値といったように、色の濃淡で情報を伝えることができます。

### 3. ダイバージェントカラー（基準を挟むプラス・マイナスを示す）

ダイバージェントカラーは、中間に基準値を挟んで、そこから両方向にシーケンシャルカラーを配置する配色です。  
例えば、摂氏0℃をを基準に、プラスは赤系、マイナスは青系のグラデーションで表すといった使い方ができます。
